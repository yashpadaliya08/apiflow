## 2. Top Navbar Controls

The top navigation bar provides global controls for your testing session:

1. **Brand Logo (`APIFlow STUDIO`)**: Click anytime to toggle between the **Studio Console** and the **Overview & Docs** landing page.
2. **Collection Dropdown**:
   - Shows active collection name (e.g. `Enterprise Storefront API`).
   - Click to switch collections.
   - Click **"+ Create New Collection"** to create a blank workspace.
   - Click the red trash icon to delete unused collections.
3. **Environment Selector**:
   - Displays active environment badge (e.g. `Development`, `Staging`).
   - Click to open the **Environment Variables Modal** to configure variables like `{{baseUrl}}`, `{{token}}`, or `{{apiVersion}}`.
4. **Execution Mode Switcher**:
   - **`⚡ Mock Engine`**: Runs client-side simulations inside the browser. No server required.
   - **`🌐 Live Proxy`**: Transmits real network requests through the local Express CORS bypass gateway.
5. **Action Buttons**:
   - **`</> Code`**: Opens the 1-click code generator for cURL, TypeScript, Axios, and Python.
   - **`⬇️ Portability`**: Opens the OpenAPI 3.1.0 & Postman 2.1 import/export dialog.
   - **`🕒 History`**: Opens the recent execution log (last 50 requests) with 1-click replay.
   - **`Overview & Docs`**: Switches to the promotional and documentation landing page.

## 3. Pane 1: Sidebar (Collection & Endpoint Explorer)

The left sidebar gives you complete control over your API endpoints:

- **Search Bar**: Real-time fuzzy search across endpoint paths (e.g. `/users`), names (e.g. `User Login`), or tags.
- **Method Filter Chips**: Click `ALL`, `GET`, `POST`, `PUT`, `PATCH`, or `DELETE` to filter the list instantly.
- **Grouped Categories**: Endpoints are automatically grouped by Resource folder (`Authentication`, `Users`, `Orders`, `Products`, `General`).
- **Endpoint Badges**:
  - `GET` — Emerald green
  - `POST` — Royal blue
  - `PUT` — Amber
  - `PATCH` — Purple
  - `DELETE` — Crimson red
- **Hover Actions**: Hover over any endpoint to duplicate it or delete it.
- **New Endpoint Button (`+`)**: Instantly creates a new endpoint draft in the active collection.

---

## 4. Pane 2: Request Builder

The center pane is where you compose and configure your HTTP calls:

- **Endpoint Name & Resource**: Edit the endpoint's friendly name and resource category inline.
- **HTTP Method Selector**: Choose `GET`, `POST`, `PUT`, `PATCH`, or `DELETE`.
- **Target URL / Path Input**: Displays the resolved base URL and allows direct path editing.
- **Mock Scenario Dropdown** *(Mock Mode only)*: Select between `200 OK`, `201 Created`, `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`, or `500 Server Error`.
- **Simulate / Send Button**: Executes the call. Also triggers with <kbd>Ctrl+Enter</kbd> or <kbd>Cmd+Enter</kbd>.
- **Request Tabs**:
  - **`Query Params`**: Key-value table for URL parameters (`?limit=24&page=1`). Enable/disable rows with checkboxes.
  - **`Path Params`**: Key-value table for path variables (`:id` or `{id}`).
  - **`Headers`**: Key-value table for request headers (`Content-Type`, `Authorization`, etc.).
  - **`Body`**: JSON editor with real-time syntax validation, automatic formatting, and the **"Generate Synthetic Body"** button.

---

## 5. Pane 3: Response Viewer

The right pane displays execution results with precision telemetry:

- **Status Code Pill**: Displays HTTP status with pulsatile indicator (`200 OK`, `404 Not Found`, etc.).
- **Latency Timer**: Shows response time in milliseconds (`24ms`) with latency jitter simulation.
- **Payload Size**: Displays human-readable payload size (`1.2 KB`, `467 B`).
- **Mode Tag**: Confirms whether the response was generated by `MOCK ENGINE` or `LIVE PROXY`.
- **Copy Button**: Copies the full JSON response body with feedback.
- **Pretty / Raw View Toggle**: Switch between formatted indentation and raw single-line JSON.
- **Headers Tab**: Inspects all response headers (e.g., `content-type`, `x-request-id`, `www-authenticate`).

## 6. Keyboard Shortcuts

| Shortcut | Action | Scope |
|---|---|---|
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> (or <kbd>Cmd</kbd> + <kbd>Enter</kbd>) | Execute Request (Simulate or Send) | Global Studio |
| <kbd>Esc</kbd> | Close Any Open Modal | Global Modals |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Navigate Between Form Fields | Key-Value Tables |
