## ⚡ Quick Start

```powershell
# 1. Clone or navigate to the project directory
cd "d:\projects\fake api testing\apiflow-studio"

# 2. Run the fullstack server (frontend + proxy)
node backend/server.js

# 3. Open in browser
# http://localhost:5000
```
