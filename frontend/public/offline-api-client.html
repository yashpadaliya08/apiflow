Frequently Asked Questions

How does APIFlow execute API calls offline?

APIFlow Studio uses high-performance client-side Service Workers and IndexedDB. Mock responses, contract simulations, and schema validations happen directly on your CPU with 0 network latency.

Does APIFlow require any external server?

No. When mocking, everything is client-side. When testing external live APIs with CORS restrictions, APIFlow includes an optional local proxy relay that forwards requests without storing payloads.
